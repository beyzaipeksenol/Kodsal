# Kodsal

Kodsal, yazılım geliştirmede kullanılan temel araçları tanıtan üç sayfalı bir web sitesidir. Araçların ne işe yaradığını ve hangi durumlarda kullanılabileceğini sade açıklamalarla sunar.

## Hedef Kitle

Bilgisayar programlamaya yeni başlayanlar.

## Tanıtılan Araçlar

- **Visual Studio Code:** Kod yazma ve proje dosyalarını düzenleme.
- **GitHub:** Kod değişikliklerini takip etme ve projeleri paylaşma.
- **CodePen:** HTML, CSS ve JavaScript örneklerini tarayıcıda deneme.
- **IntelliJ IDEA:** Java uygulamaları geliştirme ve hata ayıklama.
- **Postman:** API istekleri gönderme ve yanıtları inceleme.

## Proje Dosyaları

- `index.html`: Ana sayfa; Kodsal'ı ve hedef kitlesini tanıtır.
- `icerikler.html`: Beş araç için açıklama kartlarını ve arama alanını içerir.
- `hakkinda.html`: Projenin amacı, hedef kitlesi ve araç seçimlerini açıklar.
- `style.css`: Üç sayfanın ortak görünümünü ve responsive düzenini tanımlar.
- `script.js`: İçerikler sayfasındaki başlık aramasını, sonuç sayacını ve Temizle düğmesini çalıştırır.
- `AI_NOTLARI.md`: Projede kullanılan Copilot promptlarını ve alınan kararları belgeler.
- `TEST_NOTLARI.md`: Gerçekleştirilen arama testlerinin sonuçlarını kaydeder.
- `README.md`: Projeyi ve çalıştırma adımlarını tanıtır.

## Kullanılan Teknolojiler

Proje HTML5, CSS ve JavaScript ile hazırlanmıştır. Harici paket veya derleme adımı gerektirmez.

## Çalıştırma

1. Proje dosyalarının aynı klasörde bulunduğundan emin olun.
2. `index.html` dosyasını bir web tarayıcısında açın.
3. Araç tanıtımları için **İçerikler** sayfasına gidin.

## Arama Sistemi

İçerikler sayfasındaki arama yalnızca araç kartlarının başlıklarını dikkate alır; açıklamalarda arama yapmaz. Eşleşme büyük/küçük harf duyarsızdır ve arama metninin başındaki ya da sonundaki boşluklar temizlenir. Yazdıkça kartlar filtrelenir, görünen araç sayısı güncellenir ve eşleşme bulunamadığında boş sonuç mesajı gösterilir. **Temizle** düğmesi aramayı sıfırlayıp tüm kartları yeniden gösterir.
